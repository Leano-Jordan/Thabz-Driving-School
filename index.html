✳ GOOD TO KNOW

Before you
make a move.

A few useful things to have in mind before you get in touch.

Which licence options can I ask about?+

Current listed options include Code 8 and Code 10, Code 14, PDP guidance and driving lessons. Tell Thabz your goal so the relevant route can be confirmed.

How do I get current pricing?+

Send a WhatsApp enquiry with your intended category and the support you need. Ask for the current quote, package inclusions and any separate application or testing fees before booking.

What should I include in my message?+

Mention your current licence status, the category you're working towards and whether you need learner support, practical lessons or a complete package. That helps make the conversation more useful.
