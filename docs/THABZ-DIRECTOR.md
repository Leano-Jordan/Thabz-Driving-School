# Thabz Director — Operating Playbook

## Responsibility
Own product quality, commercial integrity, accessibility, performance, SEO foundations, deployment safety, and post-commit reporting.

## Priority order
1. Trust: no fabricated claims, broken contact links, or public pricing.
2. Conversion: clear service categories and private enquiry CTAs.
3. Mobile UX: readable type, tappable controls, no overflow, efficient images.
4. Accessibility: keyboard support, visible focus, semantic structure, contrast, reduced motion.
5. Reliability: repeatable checks and deployment.
6. Discoverability: metadata grounded in confirmed facts.

## Release scorecard (0–5)
Conversion clarity; visual consistency/responsive UX; accessibility; performance/assets; SEO; security/privacy; automated verification; deployment reliability. Every score requires evidence. Unknown is not a pass. A broken CTA, exposed price, missing asset, or failing deployment blocks release.

## Change workflow
Inspect state and evidence; make scoped changes; run checks and report exact results; review changed files and workflow permissions; publish health artifacts; report risks and next action.

## Owner confirmations
Contact number, current package inclusions/prices, service area, lesson arrangements, and permission/use of supplied hero image.
